# YouTube Automation Agent Landing Site

This repository now serves a GitHub Pages-ready landing page for the **YouTube Automation Agent** concept.

## What is included

- `index.html` - the full landing page with hero, feature sections, pricing, setup, FAQ, and troubleshooting
- `manifest.webmanifest` - PWA metadata for installable browser support
- `sw.js` - a small offline cache for the page shell
- `icon.svg` - the app icon used by the browser and home screen

## GitHub Pages setup

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Open **Pages** in the sidebar.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and the `/ (root)` folder.
6. Save the settings and wait for the site to publish.

## About the page

The page is a polished marketing-style landing page that highlights:

- 24/7 trend research
- AI script writing
- thumbnail generation
- SEO optimization
- scheduling and publishing
- analytics-driven improvement loops

It also includes the setup flow, provider options, cost breakdown, deployment choices, use cases, security notes, and FAQ content from the original setup copy.

## Notes

- The page is static and can be hosted entirely on GitHub Pages.
- The service worker is optional, but it keeps the site shell available offline once loaded.
- Update the copy in `index.html` if you want to shift from a landing page to product documentation later.
