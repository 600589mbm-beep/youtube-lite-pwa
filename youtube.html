Setup notes

What you need before the first upload.

The Google OAuth redirect must match the URL in your Cloud Console exactly, and the API project needs YouTube Data API access enabled. If your project is still unverified, uploads can remain private until the audit is complete.

Google Cloud

Create a web OAuth client, set the redirect URI to /auth/youtube/callback, and then open this page to connect your channel.

Publishing flow

Generate the content pack in the control room, render the video, drop the MP4 into uploads/, and queue it from this page when you are ready.
